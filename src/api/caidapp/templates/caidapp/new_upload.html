Path structure
Assign meanings only to path parts that carry metadata.
Upload a directory or files with relative paths to see an example here.
Optional. This is for advanced cases, for example when identity is hidden in a filename like Karel__001.jpg.
If you already assigned path parts in the simple view, the regex here is filled automatically and you can refine it.
What does the example mean? (?P<taxon>...) names the captured value taxon. [^/]+ means "one or more characters until the next slash". .* means "the rest of the path".
Examples
^(?:.*/)?(?P<locality>[^/]+)/(?P<identity>[^/]+)/[^/]+$ for a structure like Brdy/Charles/IMG_001.jpg, no matter how deep it is
^(?P<taxon>[^/]+)/(?P<identity>[^/]+)/[^/]+$ for a structure like lynx/Charles/IMG_001.jpg
^(?:.*/)?(?P<identity>[^/_]+)_\d+\.[^/]+$ for filenames like Charles_001.jpg, no matter how deep they are in directories
