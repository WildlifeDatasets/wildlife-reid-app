Optional. Use this when metadata is hidden in the filename or the simple path mapping is not enough.
If you already assigned path parts in the simple view, the regex may be filled automatically and you can refine it.
What does the example mean? (?P<taxon>...) names the captured value taxon. [^/]+ means one or more characters until the next slash. .* means the rest of the path.
Examples
^(?:.*/)?(?P<locality>[^/]+)/(?P<unique_name>[^/]+)/[^/]+$ for a structure like Brdy/Charles/IMG_001.jpg, no matter how deep it is
^(?P<taxon>[^/]+)/(?P<unique_name>[^/]+)/[^/]+$ for a structure like lynx/Charles/IMG_001.jpg
^(?:.*/)?(?P<unique_name>[^/_]+)_\d+\.[^/]+$ for filenames like Charles_001.jpg, no matter how deep they are in directories
